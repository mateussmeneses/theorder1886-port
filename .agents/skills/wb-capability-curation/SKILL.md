# wb-capability-curation

Inspect catalog, provenance, license, maintenance, and domain fit. Prefer native tools and few high-quality skills. Never automatically execute bookmarked or starred code, install MCPs globally, or transfer secrets. Record why each recommendation matters.

Verify with repository evidence, and record incomplete checks explicitly.
