# wb-project-bootstrap

Read the repository or intended stack. Select core and one or two matching profiles. Preserve pre-existing AGENTS.md, CLAUDE.md, and other rules. Preview changes, add portable skills, and document setup and test commands. Do not install MCPs without approval.

Verify with repository evidence, and record incomplete checks explicitly.
